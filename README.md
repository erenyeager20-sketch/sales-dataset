# Sales Data Summary

This repository contains a Python script that connects to an SQLite database, retrieves sales data, and displays a basic summary of total quantities sold and revenue. The results are printed in the terminal and visualized in a bar chart.

## Tools Used:
- Python
- SQLite (built-in)
- pandas
- matplotlib

## Files:
- `sales_data.db`: A sample SQLite database containing sales data.
- `sales_summary.py`: A Python script that loads the database, runs an SQL query, and displays results as a bar chart.

## Instructions:

1. Clone or download the repository.
2. Run `sales_summary.py` to generate the sales summary and bar chart.
   ```bash
   python sales_summary.py
